# Pity Sense — releases

Installers for **Pity Sense**, the gacha pull tracker for streamers (Wuthering Waves,
Honkai: Star Rail). Download the latest `PitySense-Setup-x.y.z.exe` from
[Releases](../../releases/latest). Once installed, the app updates itself from here.

`packs.json` holds game pack updates (banners, pity numbers, odds) the app picks up
without a reinstall. The app's source code is not in this repository.
